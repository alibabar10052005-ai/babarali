NETLIFY DEPLOY PACKAGE

Deploy this folder to Netlify. The original readable source files are not included.

Included protections are deterrents only: minified CSS/HTML, obfuscated/minified JavaScript, noindex/robots rules, security headers, disabled context menu/common source shortcuts, and image drag prevention.

Important: a public browser website can never be made impossible to copy because the browser must receive the assets required to render it.
